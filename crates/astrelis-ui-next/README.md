# astrelis-ui-next

Unpublished research crate for Astrelis's next retained UI engine.

It proves per-node pass invalidation, constraints-based custom layout, cached
node-local display-list fragments, cached composition, subtree-bound hit
testing, accessibility deltas, and stable generational identities.

See [`rfcs/ui-next.md`](../../rfcs/ui-next.md).
