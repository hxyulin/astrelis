# WebGPU example

Shapes, text, an image and a vector path rendered by Astrelis into an HTML canvas.
JavaScript owns input, resizing and on-demand animation frames; Rust retains GPU
resources. The sample includes high-DPI text and an MSAA toggle.

See [Astrelis for the web](../../docs/web.md) for setup, build/serve commands,
deployment requirements, API integration and browser tests.
